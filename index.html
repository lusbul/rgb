Колір із Python — на екрані

Ви налаштовуєте колір костюма персонажа. Введіть три числа в Python, скопіюйте результат сюди та перевірте колір. А потім спробуйте змінити його повзунками.

1. Код для Python

Скопіюйте й запустіть код. Введіть три цілі числа через пробіл, кожне від 0 до 255.

r, g, b = map(int, input("Колір RGB: ").split())
print(f"rgb({r}, {g}, {b})")

Приклад введення: 255 120 40
Результат: rgb(255, 120, 40)

2. Результат із Python

Сторінка також розуміє попередній формат:
Колір персонажа: RGB(255, 120, 40).

3. Колір повзунками

Змінюйте складники кольору. Значення та зразок оновлюються одразу.

Підказка: як змішуються кольори?

0 означає відсутність складника, 255 — його найбільшу інтенсивність. Чорний: 0 0 0. Білий: 255 255 255. Для сірого всі три значення однакові.

Це змішування світла на екрані. Для жовтого спробуйте 255 255 0.

Працює без інтернету. Сторінка показує колір за результатом вашої програми; Python запускайте окремо у своєму середовищі.
