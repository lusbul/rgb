Код запускається. Колір змінюється.

Ви створюєте колір костюма персонажа. Запустіть Python прямо на сторінці, введіть три числа й побачте результат. Або підберіть колір повзунками та перевірте ті самі числа своїм кодом.

1. Ваш Python-код

input() читає введений рядок, split() розділяє його, map(int, ...) перетворює частини на числа. print() виводить код кольору.

Введіть рівно три цілі числа від 0 до 255 через пробіл. Натисніть Enter або кнопку нижче. Для кількох input() можна розділити рядки символом ;.

Готово. Натисніть «Запустити Python».

Для завантаження Python потрібен інтернет. Перший запуск може тривати довше.

2. Екран виведення Python

Тут з’явиться результат print() або повідомлення про помилку.

Коли програма виведе rgb(число, число, число), фігура набуде цього кольору.

3. Колір на екрані

rgb(255, 120, 40)

Початковий зразок. Запустіть Python, щоб перевірити його.

Повзунки одразу змінюють фігуру й підставляють числа в поле введення. Код у редакторі залишається вашим. Після запуску саме результат print() задає колір.

Заявка від ігрової студії

  1. Введіть 255 120 40 і запустіть код. Якого кольору костюм?
  2. Повзунками створіть колір «Космічний лід». Перевірте його в Python.
  3. Поміняйте порядок у виведенні на rgb({b}, {g}, {r}). Запустіть із числами 255 120 40. Що змінилося?
  4. Змініть map(int, ...) на map(float, ...). Чому результат із 255.0 не відповідає формату цього тренажера?
Підказка: чорний, білий і сірий

Чорний: 0 0 0. Білий: 255 255 255. Для сірого значення R, G і B однакові. У цьому тренажері використовуємо тільки цілі числа.

Код виконується Python у вашому браузері. Повзунки керують зразком кольору; вони не імітують виконання Python.
